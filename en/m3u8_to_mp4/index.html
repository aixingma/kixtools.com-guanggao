M3U8 to MP4

Enter an m3u8 video link and convert it to an MP4 file in your browser.
Pure frontend processing — your video is never uploaded to a server.

Waiting for an m3u8 URL…
Note:
  • Only m3u8 and ts segments that allow CORS are supported. Best for short videos.
  • Conversion runs locally in your browser. First run downloads the FFmpeg core (~25MB).
  • If the source blocks cross-origin access, conversion will fail.
