온라인 M3U8 영상을 컴퓨터에 저장하는 4가지 검증된 방법

게시 2026-10-18 · 약 5분 소요

목차

  1. 방법 1 · 브라우저 변환 도구
  2. 방법 2 · FFmpeg 명령줄
  3. 방법 3 · VLC 변환 기능
  4. 방법 4 · 화면 녹화
  5. 상황별 선택 가이드

m3u8은 재생 목록일 뿐이므로 "다운로드"는 사실 조각들을 모아 하나의 파일로 엮는 작업입니다. 아래 네 가지 방법은 난이도와 소요 시간이 서로 다르니, 자신의 상황에 맞는 것부터 시도해 보세요.

방법 1 · 브라우저 변환 도구

설치를 아예 피하고 싶을 때 가장 빠른 길입니다. M3U8→MP4 변환 페이지에 주소를 넣고 실행하면 세그먼트를 이어 받아 MP4 하나로 묶어 내려줍니다. 처리가 브라우저 안에서 일어나기 때문에 영상 데이터가 외부로 전송되지 않습니다. 다만 소스가 교차 출처(CORS)를 허용해야 하고, 긴 영상은 기기 메모리에 부담이 됩니다. 10분 내외의 강의나 클립에 가장 잘 맞습니다.

방법 2 · FFmpeg 명령줄

긴 영상, 암호화 스트림, 여러 개를 한꺼번에 처리해야 하는 상황이라면 FFmpeg가 정답에 가깝습니다. 재생 목록 전체를 훑으며 조각을 내려받고 컨테이너만 갈아 끼웁니다:

# 재인코딩 없이 이어 붙이기 — 빠르고 화질 무손실
ffmpeg -i "https://example.com/vod/index.m3u8" -c copy -bsf:a aac_adtstoasc output.mp4

# 재생 호환성이 최우선일 때 — H.264/AAC로 재인코딩
ffmpeg -i "https://example.com/vod/index.m3u8" -c:v libx264 -crf 20 -c:a aac output.mp4

첫 번째 명령은 TS 조각의 AAC 오디오를 MP4 컨테이너에 맞는 형태로 정리하는 비트스트림 필터(aac_adtstoasc)를 거치므로, 처리 속도가 거의 회선 속도를 따라갑니다. 두 번째 명령은 시간이 훨씬 더 들지만 어느 기기에서든 재생되는 표준적인 파일이 나옵니다. AES-128로 암호화된 스트림도 키에 접근할 수만 있다면 자동으로 복호화해 줍니다.

방법 3 · VLC 변환 기능

명령줄이 부담스러운 데스크톱 사용자라면 VLC로도 충분합니다. 미디어 → 변환/저장 메뉴에서 네트워크 주소를 입력하고, 프로파일을 H.264 + MP4로 고른 뒤 출력 경로를 지정하면 끝입니다. 진행 상황이 화면으로 보여 처음 접하는 사람에게 편리합니다. 대신 세부 옵션 제어는 명령줄보다 제한적이고, 재생 목록 파일을 직접 열 때는 m3u8과 TS 조각이 같은 폴더에 있어야 한다는 점을 기억하세요.

방법 4 · 화면 녹화

위 방법들이 모두 막힐 때 통하는 유일한 길입니다. OBS Studio 같은 녹화 도구로 재생 화면을 그대로 담으면 소스가 난독화되어 있거나 특수한 보호가 걸려 있어도 결과물이 남습니다. 대신 실시간 길이만큼 시간이 들고, 화질은 모니터 출력을 거치므로 원본보다 떨어지며, 시스템 사운드 캡처 경로 설정도 별도로 잡아야 합니다. 일상적인 저장 수단이라기보다 "어떻게든 남겨야 하는" 상황용으로 남겨 두세요.
